Parameters Training parameters

Basic

Steps per epoch = images × repeats ÷ batch size. Total steps = steps per epoch × epochs. Setting Max train steps above 0 stops training at that step count instead.

Optimizer and learning rate

Network

LoRA dimension. Higher learns more detail and makes a bigger file.

Use a value no greater than Rank. Alpha ÷ Rank scales the strength.

Training options

Alpha mask: learn visible pixels, including the person; transparent pixels are excluded. No separate mask folder is needed. With both mask options off, learn the whole image. Gradient checkpointing saves VRAM but is a little slower.

Caption
AI caption settings and batch generation

Edit the instruction and save it under a name to reuse it as your own template.

AI needs local weights. If the output folder is empty, a .txt is created next to each image. Batch generation skips images that already have a caption unless “Overwrite” is checked; when checked, only the target captions (selected images or all images) are fully replaced and other images stay unchanged. Ctrl / Shift + click in the list on the left selects multiple images. Tagger models do not use the instruction.

Bulk tag insertion

Tags are inserted right after the trigger word, which stays first (duplicates are skipped). Ctrl / Shift + click in the list on the left selects multiple images. Results become drafts; write them out with “Save all changes”.

Mask paint

Below 100% paints lightly and builds up with repeated strokes. On save, areas at 50% or more become white (trained).

Saves the mask currently on screen (hand-painted or auto-selected) as this image's mask, replacing any saved one. Edits are auto-saved temporarily; write everything at once with “Save all changes” above. Painting and saving need no model or Python; auto-select needs GroundingDINO and SAM.

Auto-select by text (AI)

Paint / erase points are also sent to the AI. Accepts Japanese or English such as “outfit”, “jacket” or “red jacket”. You can refine the result before saving.
