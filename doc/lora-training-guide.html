1. なぜ Clip skip 2 でトレーニングするのか？

超重要
合言葉：「本番（ComfyUI）で生成するときの Clip skip ＝ 学習時の Clip skip に揃える」

SD1.5 のテキスト解釈装置（CLIP Text Encoder）は 12層 のブロックでできています。

  • Clip skip 1：最後の 12層目 の出力を使う（素の SD1.5 や完全実写系モデルの標準）
  • Clip skip 2：1つ手前の 11層目 の出力を使う（最後の1層をスキップ）

Clip skip 2 にする理由（アニメ・マージ系）

  • kimchiMix など NovelAI 系譜のアニメ／美少女マージ系モデルは、そもそも Clip skip 2 前提 で推論される。
  • 学習が 1・生成が 2 だとテキスト空間が1層ズレて、トリガーや red buruma / navy cuffs などのタグがボケる。
  • 11層目は文章全体より カンマ区切りの Danbooru タグ個別の意味 が素直に残りやすく、属性分離 LoRA と相性が良い。

Clip skip 1 にすべき例外

  • RealisticVision など 完全実写系 SD1.5 モデル を ComfyUI でもずっと Clip skip 1 で使うなら、学習も Clip skip 1 に揃える。
  • ※ SDXL / FLUX / SD3.5 のようなフロー系・別アーキテクチャでは Clip skip 設定自体は不要（アプリ側で自動無視される）。

2. マスク学習（masked_loss）の仕組みと割り切りライン

品質のキモ

マスク学習では、白（255）＝学習する衣装エリア、黒（0）＝学習しないエリア（顔・髪・背景） として誤差計算に重みを掛けます。

気になるポイント 判定 理由と実運用のコツ
衣装のフチから少しはみ出し（数px〜15px / 3〜5%） むしろプラス SD1.5 は学習時に画像を 1/8（512px → 64×64） に圧縮してマスクを当てる。ギリギリすぎると布と肌の境目（食い込み・ゴムの影・シワ）が学習から漏れて衣装が浮きやすい。少し大きめの方が自然に馴染む。
衣装の上にかかってる細い毛先（数枚だけ） ほぼ問題なし データセット全体で髪型・髪色がバラけていれば平均化される。1px単位で神経質に消す必要はない。
顔・大きな髪の塊・腕や脚が丸ごと白い 絶対NG（要修正） トリガーワードに別キャラの顔・髪型・ポーズまで引っ張られる最大の原因。顔と手足だけは確実に黒く抜く。
画面端の別キャラの服・背景のゴミ なるべく消す 不要な領域に損失が割かれるため、消しゴムでザッと削ると学習が安定する。
コスパ最強のマスク作成手順：Tools で 一括自動マスク を回す → 綺麗に出た画像に Mロック を付ける → 顔や手足が白く残った画像だけ 画面外ブラシ（Photoshop風） でザッと削る。

3. キャプション設計＆色・袖のタグ分離（Disentanglement）

応用テク

masked_loss は誤差計算を白部分だけに限定しますが、text_encoder_lr > 0 で Text Encoder も更新されるため、マスク外の無関係なタグがキャプションに大量に入っているとトークンが薄まりノイズになります。

マスク学習の最強キャプション：残すのは「4グループ」だけ

グループ 入れるタグの例 役割
1. トリガー（先頭固定） burumaGymUniform keep_tokens = 1 で常に先頭に固定し、衣装の「形・フィット感・食い込み・生地感」を吸わせる。
2. 衣装バリエーション
（マスク内の属性）		 white gym shirt, plain white gym shirt, navy collar, navy cuffs, red collar, red cuffs, navy buruma, red buruma, green buruma, white side stripes, clothes lift 色や袖・襟ラインを短い定型タグで分離。デフォルトの紺にも必ず navy buruma を書くのが分離を成功させる鉄則！
3. 構図・角度・ポーズ 1girl, solo, from front, from behind, from side, standing, sitting, kneeling, bent over, on all fours, close up, lower body, ass focus, crotch 衣装の見え方・シワ・ハイレグの伸び方を正しく学習させるために必須。
4. 質感・大枠の光 realistic, photorealistic, indoors, outdoors 実写素材でアニメモデル用の LoRA を作るとき、実写の布質感を realistic 側に逃がす（生成時に省けば綺麗なアニメ調になる）。
削るべきマスク外ノイズ（WD14 が自動で付けがち）：
髪・顔・目・表情（black hair, twintails, brown eyes, smile, teeth, mole, asian）、背景の細かい物（tree, window, curtains, potted plant, vaulting horse, volleyball）、靴・靴下・ネイル（shoes, sneakers, socks, nail polish）。

属性分離（色・袖違い）を成功させる3つのルール

  1. 長い英語文ではなく短い定型タグに統一（例：white gym shirt, red collar, red cuffs, red buruma）。
  2. デフォルト色にも必ずタグを書く（赤だけ red buruma で紺を無記入にすると、トリガー側に紺が焼き付いて色が混ざる）。
  3. 1バリエーションあたり最低 6〜8枚以上（理想 10枚〜） あると別ポーズでも安定して切り替わる。

きれいなキャプション実例

burumaGymUniform, white gym shirt, red collar, red cuffs, navy buruma, 1girl, solo, from front, standing, cowboy shot, indoors, realistic, photorealistic
burumaGymUniform, maroon buruma, cameltoe, 1girl, solo, from front, close up, lower body, crotch, spread legs, thighs, realistic, photorealistic

5. Costume LoRA Studio 便利機能＆Manual Captioner

時短ワザ

Manual Captioner（別ウィンドウ）

  • 上の Manual Captioner タブをクリックすると別ウィンドウで起動（テーマもリアルタイム同期）。
  • 自動保存あり（Folder mode）：
    • テキスト欄を編集してフォーカスを外す（blur）か Ctrl + Enter で .txt に自動保存（右上に Saved 表示）。
    • タグの Modify / Delete、Search & Replace、Add Common Caption、Append / Prepend、Delete Text も確定した瞬間に全 .txt へ自動保存。
  • ※ 折りたたみの「Drag & Drop」だけはフォルダ無しのお試しモードなのでディスク保存はされへん（実データ編集は必ず上の Load folder から開く）。

Tools ＆ プリセット自動連携

  • Cロック / Mロック：画像リスト右の鍵ボタン。ロック中は AI 自動生成・一括上書き（上書きチェックONでも）・一括タグ挿入から保護される（手動編集と保存はOK）。
  • 画面外ブラシ：画像の外側からそのままドラッグしてフチ塗りできる。
  • dataset_dir 同階層自動セット：Dataset folder に .../buru5/img を入れる（または dataset_dir 入り YAML を Import する）だけで、同階層の .../mask と .../lora が自動セット。
  • 1エポック逐次サンプル出力：学習中、1エポック保存されるたびに裏で即 sample/ へ画像を出力（VRAM不足時は学習を止めず終了後に自動リトライ）。
